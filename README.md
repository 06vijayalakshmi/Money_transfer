# Money_transfer
A Online Transaction website with complete transaction features.

#Features:

* Secure Login System with session management
* Dashboard with account overview and recent transactions
* Contact Management for quick transfers
* Money Transfer with balance validation
* Transaction History with detailed records
* Responsive Design that works on all devices
* Attractive UI with modern styling

The system is simple, secure, and provides all the essential features for a money transfer application!

#SetUp Instructions:

1.Database Setup:
 * Create a MySQL database named money_app
 * Run the SQL script to create tables and sample data
 * Update database credentials in config.php

2.File Structure:
 * Place all files in your web server directory (htdocs for XAMPP)
 * Ensure PHP and MySQL are running
